# SalahSide

A calm iPhone app for prayer times, voluntary app focus, private check-ins and daily affirmation widgets. Configure the app first, then choose a verified Apple subscription with a three-day free introductory trial where eligible.

- [Landing, Privacy, Terms and Support](front/README.md)
- [Native iOS app](ios/PrayerFocus/README.md)
- [Release preparation and remaining gates](docs/release/README.md)
- [Product requirements](docs/PRD.md)

The Xcode project, bundle IDs and product IDs retain `PrayerFocus` to preserve their technical identities. The customer-facing name is **SalahSide**.

## Development setup

Enable the existing pre-commit hook with `make hooks`. Native build and validation commands are in the iOS README; website commands are in the frontend README, and the backend template commands remain in the root Makefile.
