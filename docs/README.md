## Current decisions

- English first; iPhone, local storage and no account.
- Configure city, method, prayer conventions and app selection before membership. Setup never grants paid access or starts a trial.
- Trial and ongoing access require a verified active Apple subscription. Preserve the full annual/monthly charge and eligibility-based disclosure.
- All five prayer switches default on. Start, finish, already prayed, unlock and pause are voluntary. Missing check-ins remain unknown and never become automatic completion records.
- Calculations currently support London, New York, Toronto, Dubai and Kuala Lumpur. Match the chosen convention with a qualified reviewer/local mosque before public beta.
- Keep the approved spacious arch-and-mosque artwork and warm sand/sage palette. The Today screen has no app-name masthead.

Screen Time code and extension targets now exist, but local tests and unsigned builds do not establish physical-device behavior or Apple's distribution approval. See the release document for the exact remaining gates.
